# Licensing status

No project-wide license has been selected for the original code in this repository. There is intentionally no root `LICENSE` file or Cargo `license` declaration. Do not interpret public visibility as a general permission grant for that code.

Third-party portions retain their existing licenses and notices, listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The texts under `LICENSES/` and the codec notice files apply to those portions, not automatically to the whole repository. Copyright years in those notices are required attribution, not a project development timeline.

Before publishing a generally reusable release, the maintainer should choose a license for the original code and check compatibility with the included third-party portions. Model weights, compiled kernel packs, CUDA/NCCL, ATen/LibTorch, XGrammar, and other separately acquired artifacts have their own distribution terms. Their absence here is not a redistribution permission grant.
